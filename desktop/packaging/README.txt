ドパチル Windows 版 — インストール

1. この zip を好きな場所に展開する
2. install.cmd をダブルクリックする

%LOCALAPPDATA%\Dopachiru に入り、スタートメニューとデスクトップに
ショートカットができます。管理者権限は要りません。

消すときは Windows の「アプリと機能」から、または
%LOCALAPPDATA%\Dopachiru\uninstall.ps1 を実行してください。
設定と記録(%APPDATA%\dopachiru)は残ります。

ログイン時に自動で立ち上げたいときは、ドパチルを開いて
設定 → 起動 から入れてください。
