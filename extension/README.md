# ドパチル ブラウザ拡張 (Chrome / MV3)

URL でページを止めるための目と手。**判定はここではしません。**

## なぜ判定を持たせないか

拡張が独自にブロック先の一覧を持つと、ルールが二重帳簿になります。
時間帯・連続使用時間・ポイント・罰・押し切りの代金は本体にしか無いので、
そのままだと「アプリでは止まるのに、ブラウザでは素通り」がすぐ起きます。

判定は `:core` の1か所だけ。拡張の仕事は3つです。

1. いま見ているページの URL を本体に伝える
2. 本体が「塞ぐ」と答えたら、そのタブを退避させる
3. 本体が「これを消して」と答えたら、ページの中でそれを消す

2 が要るのは、**本体の全画面を被せても裏のタブの音は止まらない**からです。
動画は鳴り続けるので、そこだけブラウザ側で手を出す必要があります。

## 3. ページの中で消す(音だけにする)

本体の「音だけにする」は全画面を覆うやり方ですが、ブラウザではそれが使えません
── 作業の資料として動画を鳴らしたいのに、検索欄も他のタブも一緒に覆われて
しまっては、用途そのものが潰れます。

そこでブラウザだけは、**動画の絵だけをページの中で消します**(`veil.js`)。

- **音は鳴り続けます。** `opacity:0` にするだけで、再生も音量もそのまま
- **サムネイルは消しません。** 見て選ぶ手がかりは残ります
- 消すのは映像・進捗バーのコマ送り・画面外に滲むシネマティックの3つ

ルールの「音だけにする」に2つのチェックが足してあります(ブラウザでのみ効きます)。

| チェック | 消えるもの |
|---|---|
| おすすめも消す | ホームの一覧・横の関連動画・終わりぎわのカード・ショートの棚 |
| 検索からしか選べなくする | ホームと急上昇。`/shorts/…` は同じ動画の**普通の再生ページへ移す** |

ショートを塞がずに移すのは、見ようとしたものを取り上げないためです。
取り上げたいのは**次から次へ流れてくる縦の列**のほうで、そこが無くなれば1本で終わります。

対象は `youtube.com` と `nicovideo.jp`。本体に届かないときは**何も消しません**
── 塞ぐときと同じで、本体が落ちただけで映像が消えたままになるほうが困ります。

なお、消しているあいだは左下に「ドパチル」と出ます。黙って消すと壊れたと思って
設定を触りに行くことになるので、誰が消したのかは見えるようにしてあります。

## 入れかた

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」でこの `extension/` を選ぶ

## つなぎかた

合言葉のやり取りが要ります。**入力はしません。**

1. **ドパチル本体** → 設定 → ブラウザ拡張 → 「ブラウザ拡張とつなぐ」を押す
2. その2分のあいだに、**拡張の設定**(拡張一覧 → ドパチル → 詳細 → 拡張機能のオプション)で「本体につなぐ」を押す

これで合言葉が渡ります。以降は拡張が覚えているので、繋ぎ直しは要りません。

うまくいかないときは、拡張の設定の「状態を見る」を押すと、
本体が見つからないのか・まだ繋いでいないのかが分かります。

## 外に何も出ないこと

- 通信先は `127.0.0.1` だけ。**同じ機械の外には出ません**
- 本体も `127.0.0.1` にしか bind しません(他の機械からは届かないことをテストで見ています)
- ブラウザで開いた**ただのページも** `fetch("http://127.0.0.1:…")` を投げられるので、
  受け口は2枚重ねで守っています
  1. `Origin` が `chrome-extension://` のものしか受けない。この見出しはブラウザが付けるので、ページ側からは偽れない
  2. 合言葉。本体で「つなぐ」を押してから2分のあいだしか配らない

## 本体が起きていないとき

**既定は「通す」です。** 本体が落ちただけでブラウザが丸ごと使えなくなるほうが、
取り返しがつかないためです。逆に、本体を終了させれば抜けられるということでもあります。

塞ぐ側にしたい場合は、拡張の設定のチェックを入れてください。

同じ理由で本体の側にも時限があります。**拡張から2分半連絡が来なければ、
URL の規則は自動的に外れます。** 拡張を消したまま塞がり続けることはありません。

## 作りの都合

- 近況は 30 秒ごと(MV3 の目覚ましの下限)。ページを移ったときは即座に伝えます
- ポートは 48731 から順に4本試します。変えるときは
  `LocalBridge.PORTS` と `background.js` の `PORTS` の**両方**を直してください
- 退避ページ (`blocked.html`) に押し切るボタンは置いていません。
  続ける判断は、反省文と待ち時間と代金がついている本体の画面でさせるためです
